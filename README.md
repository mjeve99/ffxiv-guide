# FFXIV DPS 가이드

파이널판타지14 딜러 13종 기술 & 단축키 참조 페이지

## 사용법

`ffxiv-dps-guide.html` 파일을 브라우저에서 열면 됩니다.

GitHub Pages 활성화 시: https://mjeve99.github.io/ffxiv-guide/ffxiv-dps-guide.html

## 포함 직업

**근딜**: 몽크, 용기사, 닌자, 사무라이, 리퍼, 바이퍼  
**원딜**: 음유시인, 기공사, 무도가  
**마딜**: 흑마도사, 소환사, 적마도사, 픽토맨서

## 기능

- 직업별 핵심 메카닉 요약
- 단축키 키보드 레이아웃 시각화
- 기술 목록 (xivapi 아이콘 자동 로드)
- 2분 버스트 로테이션 흐름
- 기술명 클릭 → Garland Tools 연결

## 2026-09-24 기공사 배치

마우스 양쪽 버튼 이동 기준으로 123 기본 콤보, QWER 도구, ASD 준비 기술을 배치했습니다. G·Shift+G·Ctrl+L 및 추가 기능키를 연습기에서 사용할 수 있습니다. 변화 기술도 같은 입력 키에 연결됩니다. 이후 전체 직업 배치도 아래와 같이 통일했습니다.

바로 열기: https://mjeve99.github.io/ffxiv-guide/ffxiv-dps-guide.html#mch

## 2026-09-24 전체 직업 · HUD 2

13직업의 전투 키를 역할별로 정리했습니다. 마우스 양쪽 버튼으로 이동하며, 123456 기본 공격, QWER 핵심 기술, ASD 준비·연계, G/Shift+G 이동·특수 기술을 사용합니다. 직업 특성에 따라 예외가 있으며 각 기술 설명에서 확인할 수 있습니다. T 질주, F4 넉백 방지, Ctrl+L 리미트 브레이크는 공통입니다. M 지도, I 소지품 등 메뉴 키는 유지합니다.

HUD 저장 배치 2의 단축바 위치·배율·방향을 바탕으로 직업별 전체 화면 및 확대 PNG 26장을 제공합니다. 공유 단축바는 기존 내용을 유지하는 회색 표시이며 실제 게임 캡처가 아닙니다. 사이트는 게임 설정 파일을 변경하지 않습니다.

연습기는 직업별 기본 연계와 원본 오프너를 구분하며, 자동 변화 기술은 같은 키에 연결합니다. 조건부 오프너는 사용자가 선택해서 편집할 수 있습니다. 이전 저장 연습 기록은 배치 이력에 보관합니다. 13직업 × 40문항 입력, 연계 프리셋, 36개 키와 아이콘 파일을 검증했습니다.
