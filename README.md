# FFXIV DPS 가이드

파이널판타지14 딜러 13종 기술 & 단축키 참조 페이지

## 사용법

`ffxiv-dps-guide.html` 파일을 브라우저에서 열면 됩니다.

GitHub Pages 활성화 시: https://mjeve99.github.io/ffxiv-guide/ffxiv-dps-guide.html

## 포함 직업

**근딜**: 몽크, 용기사, 닌자, 사무라이, 리퍼, 바이퍼  
**원딜**: 음유시인, 기공사, 무도가  
**마딜**: 흑마도사, 소환사, 적마도사, 픽토맨서

## 기능

- 직업별 핵심 메카닉 요약
- 단축키 키보드 레이아웃 시각화
- 기술 목록 (xivapi 아이콘 자동 로드)
- 2분 버스트 로테이션 흐름
- 기술명 클릭 → Garland Tools 연결
